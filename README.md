# 弦记 · Fret Notes

像记单词一样，逐步记住吉他指板上的音名与位置。

## 两阶段计划

**第一阶段：HTML 网页版（当前阶段）。** 以 GitHub Pages 发布，先完善 0–12 品、78 个位置的听音、唱名显示、认识卡、双向练习与间隔复习。用户通过网址打开；学习记录继续保存在各自浏览器中，可导出和恢复备份。

**第二阶段：微信小程序（后续阶段）。** 延续同一套指板与练习设计，复用 `logic.js` 中的平台无关逻辑；届时适配小程序界面、音频和本地存储，并安排真机验收与发布。当前目录交付的是第一阶段网页源码。

## 发布到 GitHub Pages

本目录已经包含网页入口 `index.html` 和配套资源，可从仓库根目录直接发布，无需安装依赖或配置构建工作流。

详细操作见 [PUBLISH.md](PUBLISH.md)。上传时把**本目录内的文件**放到仓库根目录；在仓库 `Settings → Pages` 中选择 `Deploy from a branch`、实际发布分支和 `/ (root)`。只有把源码推送到 GitHub 并启用 Pages 后，才会产生在线访问地址。

## 直接使用

双击 `dist/弦记.html`，用现代浏览器打开即可。不需要安装依赖，不需要账号，不依赖网络。也可以直接打开源码目录中的 `index.html`，此时请保留同目录下的 `styles.css`、`logic.js`、`audio.js` 和 `app.js`。

推荐的第一次练习：

1. 保持默认的「第 6 弦 · 路标音」。
2. 点击「先认一遍」，翻开五张认识卡，把位置与音名对应起来。
3. 开始「看音找位置」，在题目指定的弦与品位范围里点击答案。
4. 再试试「看位置认音」，反过来回忆音名。
5. 有到期卡时点击「开始复习」；完成后隔一阵子再练。

手机窄屏下，指板可以横向滑动。指板最上面是最细的 1 弦，最下面是最粗的 6 弦。0 品代表空弦。

## 包含的功能

- 认识卡：先观察位置，再翻开音名，可播放合成参考音，并用设备本地语音念出固定唱名。
- 双向回忆：看音找位置 / 看位置认音。
- 六个单元：第 6 弦路标、第 5 弦路标、低音弦自然音、中间弦自然音、高音弦自然音、整块指板。
- 每轮通常 10 题，最多引入 5 个新位置。认识卡后的练习沿用刚学过的位置。
- 错题回访：答错后，在本轮后面再安排一次；每个位置每轮最多额外回访一次。
- 间隔复习：记录每个「弦＋品」位置的复习等级与到期时间。
- 指板地图：0–12 品共 78 个位置均配有实际音高，每格显示音名与固定唱名，可按音名筛选；筛选后变淡的位置仍能点击试听。
- 我的进度：记忆热图、最近 7 天答题量、正确率、连续练习天数。
- 本机保存，以及 JSON 备份的导出、恢复。
- 适配宽屏与窄屏的布局；可用 Tab、Enter 操作，指板按钮支持方向键移动焦点。

## 记忆规则

每个位置独立记录。按时答对后，下一次复习间隔依次为：

`10 分钟 → 1 天 → 3 天 → 7 天 → 14 天`

达到最高等级后，继续按 14 天安排。提前加练会记入成绩，但不会提升等级或推迟原到期时间。答错会将等级重置，并在 1 分钟后到期。本轮的错题加练与到期安排同时存在。

「长期记忆」是界面上的练习指标：至少三次按间隔答对后点亮，答错则退出。它不是对实际记忆效果的保证，也不是 FSRS 等经过拟合的个人化模型。

连续练习、每日目标与近 7 天统计，使用浏览器所在设备的本地日历日期。

## 数据与隐私

所有数据写入当前浏览器的 `localStorage`，应用没有后端，也没有分析统计或外部资源请求。

不同浏览器、不同网址、本地文件副本之间的存储可能相互独立。浏览器对本地文件存储的处理也可能不同；如果存储不可用，页面会提示，本轮仍可练习。建议在「我的进度」里定期导出备份。

恢复备份会替换当前记录，页面会先确认。清空记录前也会确认。

## 开发

纯 HTML、CSS 和 JavaScript，无第三方依赖。运行网页不需要 Node.js；只有运行测试与重新生成单文件时才需要 Node.js 18 或更高版本。

```powershell
npm.cmd test
npm.cmd run build
```

也可以直接运行：

```powershell
node --test tests/*.test.cjs
node build.cjs
```

源码职责：

- `index.html`：页面骨架、导航、说明与对话框。
- `styles.css`：完整视觉样式与响应式布局。
- `logic.js`：音名计算、课程、出题队列、间隔复习与数据校验。
- `audio.js`：音高播放、本地唱名语音、静音和快速点击取消控制。
- `app.js`：认识卡、练习、地图、进度、音效和备份交互。
- `tests/logic.test.cjs`：核心逻辑测试。
- `build.cjs`：把样式和脚本嵌入 HTML，生成 `dist/弦记.html`。

`logic.js` 同时提供浏览器全局 `FretNotes` 与 CommonJS 导出，便于后续扩展和复用。

## 当前范围与验证

适用于标准调弦 E–A–D–G–B–E 的 0–12 品，包含升降音同音异名。参考音使用 Web Audio 合成，保留各位置的实际八度。固定唱名为 C=do、D=re、E=mi、F=fa、G=sol、A=la、B=si；升降音显示如「升 do / 降 re」。这是固定唱名，不会随歌曲调性改变。

顶部喇叭控制自动声音，「唱名」控制语音朗读。新用户默认开启两者，旧记录保留原来的静音设置。地图上方的「点击发声：开／关」同步控制声音，点击每个格子都能播放其实际八度的音高和唱名；认识卡在翻开时播放，练习在作答后播放。明确的「试听」或「听音与唱名」按钮可以在静音时单次播放。

唱名使用 Speech Synthesis，仅选择设备已安装的本地中文或英文语音，不使用网络语音。它是念唱名，不是按对应音高歌唱；音乐音高由合成参考音提供。没有适合的本地语音或浏览器不支持时会提示，音高和唱名文字仍可用。首次语音加载较慢时可稍后再次点击试听。

已经完成脚本语法检查和 30 项音名、记忆和声音控制测试，包含全部 78 个位置的音高与唱名检查（声音控制使用模拟浏览器环境），全部通过。内置浏览器的安全策略禁止打开本地 `file:` 页面，本次未完成真实浏览器的视觉与端到端操作验收。响应式样式已实现，仍建议在自己的桌面与手机浏览器上实际体验。
